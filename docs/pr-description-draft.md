# PR #2 설명 교체 초안 — 원격 미반영

현재 재구성 후보와 승인 전 상태는 docs/poc2-ci-transition.md를 기준으로 합니다. 이전 로컬 커밋·보존 위치를 복구하지 못해 현재 원격 HEAD 직후로 후보를 준비했으며 실제 원자료 9개 파일은 후보 트리에 포함하지 않았습니다. 원자료의 지속 보관은 미확정이고 UI28개/원격 CI는 미실행입니다. 이 문서도 원격에 게시하지 않았습니다.

실제 자료를 읽던 공개 회귀시험을 명시적인 허구 fixture로 교체하고, 공개 입력/CI 산출물 검사를 추가합니다. 기존 분석·승인 차단·저장/재열기·작성/Word 구현은 유지합니다.

원자료의 영구 보관 위치가 승인되지 않아 기존 실제 자료 파일은 로컬에서 보존 대기 중입니다. 전체 공개 자료 경계는 해당 정리가 끝날 때까지 차단됩니다. 공개 준비 완료나 실제 모델 분석 품질 통과를 의미하지 않습니다.

로컬 lint·typecheck·전체 단위시험 147개·build·검토 입력/실패 trace 텍스트 검사는 통과했습니다. UI 28개는 Chromium 실행 파일 및 WebKit 라이브러리 부족으로 launch 단계에서 실패했으며 앱 동작 통과를 의미하지 않습니다. 원자료 9개 파일/21개 발췌의 바이트·본문 해시를 보존 대조했습니다. 실제 파일 정리와 전체 공개 경계 통과, 정상 UI 재검증은 남아 있습니다. 상세 대응은 docs/public-data-separation.md에 기록했습니다.

원격 push·PR 본문 수정·Preview 생성은 아직 승인되지 않았으므로 이 문서는 제출용 초안입니다. 과거 공개 커밋/캐시/외부 사본은 별도 위험으로 남습니다.
