# 구현 기본 결정과 남은 사용자 결정

기본은 한국어·국내 시장·개인 검수·6개 채널이다. 자동 기능은 실제 비용과 계정이 정해지기 전까지 비활성이고, 수동 기능은 API 없이 동작한다.

| 항목 | 현재 상태 | 연결 전 처리 |
|---|---|---|
| D1 검수판의 이용 범위 | 미정; 개인용으로 구현 | 팀 초대·공개 가입 없음 |
| D2 공급자·시험 비용 | 미정; 유료 호출 0회 | 모의 응답·유료 호출 차단 검증 |
| D3 대표 검수 브랜드/제품 | 미정 | 허구임을 명시한 고정 자료로 기능 검증 |

기술 선택: 기존 Next.js를 유지하고, 별도 계정이 없어도 로컬 프로젝트와 수동 경로를 사용할 수 있게 한다. 인증·서버 저장은 실제 연결 전에 완성하고 별도 검수한다.
