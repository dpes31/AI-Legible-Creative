# 구현된 관계와 아직 남은 관계

수동 화면은 `Project` 한 개를 IndexedDB의 단위로 저장합니다. 제품 모델은 별도 입력이며 모델 변경 시 새 작업을 만듭니다. 주장은 출처 UUID를 참조하고, 문서의 블록은 주장 UUID를 참조합니다. 이전 localStorage 원본은 해시로 중복 감지하며 복제본을 남긴 다음 별도 프로젝트로 전환합니다. 출처의 정확한 인용 문자열을 본문에서 찾는 검사는 의미 검증과 별개입니다. 외부 AI 응답의 `verified`나 경쟁 우위 표시는 승인 상태로 가져오지 않습니다. 경쟁 비교 조건이 확인되지 않으면 제안된 우위는 보류하고 작성 요청문에서 제외합니다.

자료 입력→수동 조사(`alc.research.v1`)→원문 대조→채널 작성(`alc.content.v1`)→개별 문서의 코드 검사와 사람 확인→복사·TXT·ZIP 순서입니다. 문서 편집은 그 채널만 `stale`로 만들고, 입력·출처를 바꾸면 연결된 분석과 문서 상태를 낮춥니다. 실제 외부 AI 전달 허용과 출처의 공개 사용 허용은 각각 별도 선택입니다. 두 허용이 모두 있는 근거만 외부 AI 작성 요청문에 포함합니다. 자료 변경 후 이전 요청 ID는 무효로 만듭니다.

서버에는 Supabase Auth의 사용자 토큰으로 접근하며 RLS로 소유자별 조회를 제한하는 프로젝트 및 실행 테이블·SQL이 있습니다. 실행 예약은 DB 예산 행을 잠근 뒤 생성하며 단계 선점은 한 번씩 수행합니다. OpenAI 어댑터는 웹 검색 응답의 실제 인용과 별도 구조화 응답을 받도록 분리되어 있고, 모의 공급자 단위 검사가 있습니다. **실제 서버·계정 연결, 이 실행 결과를 프로젝트에 안전하게 반영하는 흐름, 재개·정산·채널별 검증은 아직 완성되지 않았습니다.** 비용 정산이 없는 상태에서 환경변수만으로 유료 호출이 켜지지 않도록 실행 경계 자체가 503을 반환합니다. 현재 자동 모드를 선택해도 사용자 화면은 수동 작업을 안내합니다.

현재 코드 검증은 숫자·인증·우위 키워드의 무근거 사용, 누락 조건, 자리표시자와 연결 ID를 중심으로 수행합니다. 공개 문장을 하나씩 사람이 원문과 의미·조건을 대조하거나 사실 주장이 없는 표현임을 확인해야 최종본으로 표시합니다. 본문 수정 시 문장별 확인을 모두 무효화합니다. 일반 서술문의 숨은 사실 주장·의미상 지지 여부·가격 조건 비교는 자동 검증되지 않습니다. 따라서 콘텐츠 성과나 독립적 사실 검증 완료를 주장하지 않습니다.
