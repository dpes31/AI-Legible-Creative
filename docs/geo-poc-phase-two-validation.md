# PoC 2단계 기술 검증과 자료 분리 기록

최종 기능 기준 d028676ccf0eeb46871d7e2a9c3bedb93a6fd68f는 당시 단위143개·UI28개·lint/typecheck/build를 통과했다. 후속 자료 사전 대조 기준 f3166d08e4cb35c790d05c44d5060153f0cad205는 당시 단위144개·UI28개 등을 통과했다. 이 기록은 과거 결과이며 이번 수정 검증이나 실제 모델 분석 결과로 전용하지 않는다.

질문 발견 입력과 모델/요청문/원본 응답·실패·검토/기각·stale 이력을 보존하고, 자료·권한·메타데이터·모델·요청문·응답 변경을 재검증한다. Source ID 또는 해시만으로 타당성을 승인하지 않으며 작성용 질문으로 자동 전달하지 않는다.

현재 공개 회귀 입력은 새로 작성한 허구 발언·사양·응답으로 교체한다. 과거 실제 원문을 읽던 시험은 안전 조건의 대응 관계를 유지하고 제목과 검증 수준을 표시한다. 원자료의 보관 승인 전 정리는 해당 단계만 보류한다. 상세 현재 결과는 public-data-separation.md에서 실제 실행 후 기록한다.

실제 UI 수집/해석 품질, 실제 외부 모델의 누락·과잉·순서 안정성, 실제 사용자 의미 승인은 별도 검수다. 공개 화면/응답에 실제 원문이 포함된 과거 artifact 링크는 이 문서에 재수록하지 않는다.
