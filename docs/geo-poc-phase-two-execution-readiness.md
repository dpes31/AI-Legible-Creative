# 실제 모델 실행 준비 상태

현재는 준비 단계다. 실제 외부 모델 실행과 원자료 전송은 미승인이다. 공개 회귀시험의 자료·응답·권한/의미 검토 클릭은 모두 허구 동작이다.

B안은 적법한 기존 실제 소비자 자료 4~6개를 대상으로 하며 관리 주체·외부 처리 정책·허용 계정·원문/권한/실행 기록의 보관 위치를 먼저 확인한다. 회사 원문이나 동의서 제출을 무조건 요구하지 않는다. 실제 원문·권한 문서·원문 대응표는 Public Git/CI/배포에 넣지 않는다.

모델 후보는 실제 계정 선택 가능 여부와 환경을 확인한 후 확정한다. Work의 기억·이전 문맥·앱·검색 통제와 한계를 기록하고, 일반 Chat 등으로 바뀌면 별도 조건 버전으로 승인받는다. 입력·요청문·응답 원본과 실패도 보존한다.

초기 정순·역순·해시 순서3회는 탐색이다. 같은 순서 반복을 추가하는6회는 별도 승인 범위로 구분한다. 동일 순서의 변동과 순서 간 차이를 독립 평가하고 작은 표본의 결과를 대표 수요·전체 품질 검증으로 확대하지 않는다.

정확한 전송 ID·해시·이용 근거·비식별·원문 대응·허용 저장 위치·서비스/모델·실험 조건이 확정된 표에 대한 사용자 승인 전에는 실행하지 않는다. 자료별 출처·위험 상세는 이 공개 문서에 재수록하지 않는다.
